# Paper Collage Carousel Ops

Create a coherent, image-led teaching sequence whose physical visual language
supports a useful promise. This specializes carousel art direction; use the
existing carousel/publishing workflow for export, account and release mechanics.
Resolve creator-specific branding, reference posts, rejected versions, voice and
approved copy from the private project. Keep those details outside this skill.

## Inspect before inventing

- Inspect actual reference covers and representative interiors beside the current
  draft. For animated pages, inspect both the fully revealed state and the reveal
  sequence. An empty first frame is not evidence of an empty composition.
- Record what is observed versus inferred: hierarchy, text density, relative
  scale, margins, layering, material, recurring objects, focal point and timing.
  Do not claim a creator's software, fonts or performance from appearance alone.
- Extract transferable principles, not another creator's exact composition,
  wording, mascot or artwork. If references cannot be retrieved, disclose the
  gap and use saved images with provenance rather than an imagined style.
- Separate visual critique from copy critique. Freeze copy when comparing
  production approaches; revise a weak promise explicitly rather than silently
  changing the subject during a design pass.

## Lock one visual system

Write a short project-local specification before expanding the sequence:

- A light paper/material base, readable ink colour, one principal accent and
  limited secondary category colours where they carry meaning.
- An actual available display/body type pairing, with a small annotation style
  if useful. Specify sizes, line breaks, width, line spacing and margins on the
  real output canvas. Do not assume naming a serif creates editorial hierarchy.
- A consistent light/shadow treatment, edge detail, texture scale and layering
  order. Gentle material variation should coexist with precise text alignment.
- A recurring visual vocabulary such as tabs, source clippings, highlights,
  arrows or cropped photographs. Use it to explain relationships rather than
  decorate every empty corner. A portrait is optional; an invented logo is not
  a substitute for creator identity.

Read [the production recipe](references/production-recipe.md) when selecting
assets, building layers or diagnosing flat synthetic-looking output.

## Build the smallest representative pair

For a new or rejected visual direction, produce a cover and one worked-example
interior first. Default to 1080×1350 for carousel review unless the destination
requires another canvas; compose a separate 9:16 adaptation for a Reel.

The cover needs an immediately understandable outcome or useful count, a clear
reading path and one dominant visual. The interior must teach something concrete:
an actual excerpt, action, comparison or traceable example. Abstract black lines
may help a concept sketch, but cannot serve as the tutorial's final evidence.

Prefer a hybrid build: original/appropriately licensed material and illustration
assets, with editable deterministic type and layout. Code can composite rich
assets; SVG is not intrinsically unsuitable. Conversely, requesting a complete
slide as one generated image does not ensure readable copy or consistent pages.
Use the environment's approved image-generation tool when generating assets;
record generated illustration separately from authentic screenshots and proof.

## Judge rendered pixels

Show the reference, prior draft and new pair at comparable phone size. Inspect:

- Can a viewer identify the promise and first reading target immediately?
- Does type hierarchy survive reduction, without cramped wrapping or a footer
  competing with the lesson?
- Do paper edges, texture, overlap and shadows feel like one material system,
  rather than flat rectangles or unrelated sticker effects?
- Does the main visual explain this specific idea? Is the worked example useful
  without reading the caption? Is generated imagery clearly illustrative?
- Does the pair share a recognizable grammar while avoiding an identical layout
  on every page? Is text clear of meaningful image details and UI safe areas?

Return specific visual differences and remaining defects with actual images.
Do not treat dimensions, successful decoding, a rubric score or a second model's
approval as the creator's taste acceptance. A model swap that also changes the
renderer/assets is a production comparison, not a controlled model benchmark.

After the pair is accepted, extend its system to the full sequence. For motion,
animate the teaching operation—highlighting evidence, moving a source clipping,
revealing an annotation—then hold the completed state long enough to read.
Avoid motion that continually delays the useful content. Check actual playback.

## Handoff

Preserve versioned source layers, asset provenance, the design specification,
cover/interior preview, concrete example sources and a short revision note.
Keep unresolved factual, visual and creator decisions distinct. Preserve old
drafts. Concept approval is not publishing approval; prepare the exact final
media, caption and resource promise for the applicable release workflow.
