# Interview Guide

Use the interview to expose assumptions before scoring. Ask one question at a
time. Summarize the answer, state the implication you would record, and let the
person correct it.

## 1. Frame the Decision

Ask:

1. What period are we allocating: a week, sprint, quarter, or year?
2. How much genuinely discretionary capacity exists after sleep, health,
   relationships, care work, and fixed commitments?
3. What must remain true at the end of this period even if progress is slower?
4. What current chapter is this allocation supposed to advance?
5. Which commitments are hard floors, and which are inherited habits?

Recommended default: use a one- or two-week sprint for first use. Longer
horizons hide feedback and make uncertain estimates look more stable than they
are.

## 2. Define the Lanes

Ask the person to name three to seven lanes. Rewrite each lane as:

```text
<work system> -> <near-term outcome> -> <durable asset, if any>
```

Examples:

- salaried role -> preserve income and earn promotion evidence -> career capital
- product prototype -> test one customer problem -> technical proof and learning
- educational publishing -> ship two useful pieces -> distribution and trust

Reject lanes that overlap so heavily that the same hour could count toward both.
If overlap is intentional, name one lane as the primary owner and list the
other as a beneficiary.

## 3. Gather Evidence

For each lane, ask:

1. What happened in the last 90 days that supports allocating more effort?
2. What concrete result is plausible in the next 90 days?
3. What existing income, runway, credential, or option does this protect?
4. What asset remains useful in ten years even if this project fails?
5. Which work textures reliably create or drain energy?
6. How does success move the person toward the stated direction?
7. What higher-value alternative loses time if this receives another block?
8. Where has the lane already absorbed enough effort that the next block is
   less valuable?
9. Which claims are measured, observed, inferred, or merely hoped for?

Require at least one evidence statement for any score above 70. A preference is
valid evidence for fit, but not for revenue.

## 4. Score the Next Marginal Block

Use the anchors in `scoring-model.md`. First ask the person for a range, then
record a base-case value for the current run. Score the next four to eight
hours, or the next 10% of capacity, rather than the lane in the abstract.

## 5. Apply the Grilling Pass

Probe contradictions:

- If this lane succeeds wildly, do you want the obligations and identity that
  follow?
- If nobody were impressed, would the work still be worthwhile?
- Are you calling avoidance “exploration”?
- Are you calling fear “downside protection”?
- Are you counting the same income or asset in more than one factor?
- Does a high score depend on a credential, audience, customer, or access you
  do not yet have?
- What evidence would make you cut this allocation in half next sprint?
- What would have to be true for the rejected lane to become the best bet?

## 6. Set Floors, Caps, and Dependencies

Use a floor only for:

- contractual or care obligations
- minimum viable maintenance
- recovery and health protection
- affordable strategic exploration

Use a cap when:

- available work cannot productively absorb more time
- recovery or relationships would be harmed
- the lane has a queue or external dependency
- marginal learning has flattened
- concentration risk becomes unacceptable

Represent a dependency as a note or make the lane ineligible until the
dependency is satisfied. Do not conceal a blocked lane by giving it a low
strategic score.

## 7. Close the Interview

Before calculating, reflect:

- the decision frame
- the lanes
- the hard constraints
- the most uncertain assumption
- any answer that materially conflicts with another

Ask for correction only when it would change the recommendation. Otherwise run
the model and label the assumption.
