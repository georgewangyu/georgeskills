# Voice Profile Schema

Use this structure when building a reusable voice profile.

```text
VOICE PROFILE
=============
Subject:
Channel:
Goal:
Confidence: high / medium / low

Source Set
- [sample, date if known, channel, why it matters]

Rhythm
- Sentence length, paragraph length, fragmentation, pacing.

Compression
- Dense vs explanatory. What gets assumed, what gets spelled out.

Claim Style
- How strongly claims are made.
- How evidence, receipts, numbers, examples, or caveats appear.

Emotional Register
- Warm, dry, blunt, playful, skeptical, earnest, restrained, etc.
- What kind of enthusiasm is allowed.

Preferred Moves
- Recurring moves the writer actually uses.
- Examples: starts with concrete event, uses contrast, names process failure,
  admits uncertainty, uses a small joke, asks a direct question.

Banned Moves
- Patterns the writer rejects or does not use.
- Include only source-observed patterns or user-stated preferences.

Vocabulary
- Common words, favorite phrases, tolerated jargon, words to avoid.

Punctuation and Formatting
- Dashes, colons, parentheses, bullets, emoji, capitalization, line breaks.

Channel Notes
- X:
- LinkedIn:
- Email:
- Blog:

Rewrite Instructions
- Operational rules another agent should follow when drafting in this voice.
```

Keep the profile short enough to paste into another drafting task. Prefer
concrete bullets over literary analysis.
