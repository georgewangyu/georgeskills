# Carousel Design-Language Patterns

Use these patterns when building branded Instagram carousel systems.

## Slide Grammar

- Cover: one hard claim that creates a reason to swipe.
- Problem: name the failure mode in plain language.
- Framework: turn the idea into a diagram, checklist, or rule.
- Proof or contrast: show what the bad version misses and what the useful version adds.
- CTA: ask for a save, reply, or follow through a concrete next step.

## Visual System

- Use `1080 x 1350` as the default educational carousel frame.
- Treat every slide as mobile-first: large type, short lines, generous margins.
- Add a compact brand mark, handle, and slide count to make the series recognizable.
- Build a palette with contrast and tension, not just variants of one color.
- Keep framework slides diagrammatic; save photos/video windows for cover, proof, or CTA emphasis.

## Motion Patterns

- Human loop: short portrait or talking-head clip used as a personal-brand anchor.
- Cursor scan: pointer, highlight, or selection motion that makes technical work legible.
- Receipt reveal: checks, proof artifacts, or logs appearing one step at a time.
- Process marker: a dot or badge moving through a diagram.
- Demo window: a screen recording or product clip embedded in a branded frame.

## Variant Discipline

- Preserve previous drafts.
- Create named variant folders for substantial visual changes.
- Export a contact sheet for every serious candidate.
- Add the best variant to the editable design-language reference after approval or strong user signal.
