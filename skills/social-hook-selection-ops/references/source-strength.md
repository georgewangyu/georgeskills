# Source Strength Reference

Use this reference when selecting or documenting short-form hooks.

## Labels

| Label | Meaning | Use |
|---|---|---|
| `proven` | Worked on the user's own account or has strong owned-account precedent. | Reuse first when the new idea fits. |
| `proven-adjacent` | Close to the user's proven lane but not independently validated as a repeatable winner. | Use when the format is nearby but the angle is newer. |
| `source-observed` | Observed from another creator/account with source notes and some performance evidence. | Adapt the structure, not the creator's identity. |
| `candidate` | Plausible but not validated. | Use when exploring or when stronger evidence does not fit. |

## Promotion Rule

Only promote a hook to `proven` after the user's own post beats baseline or
clearly outperforms comparable posts.

## Evidence To Capture

- platform
- creator/account or owned account
- source URL
- first spoken line or on-screen premise, paraphrased when needed
- first visual frame
- views and account size when available
- why the hook worked
- reusable pattern
- adapted user-native version
