# Vertical Layout Grammar

Use layout changes to follow the argument: speaker for the claim, proof for the
example, takeover for legibility or mechanism, and speaker for the payoff.

## FACE

- Fill the `9:16` canvas with a tracked crop from the highest-resolution
  original camera source.
- Keep the eyes inside the upper-middle safe area and allow natural hand
  movement when possible.
- Use a wider crop for setup and a tighter crop for emphasis; avoid arbitrary
  digital punches.

## SPLIT

- Reserve roughly the upper `40-55%` for a screen, diagram, or proof object and
  the lower `45-60%` for the speaker.
- Treat the ratio as content-dependent, not a fixed template.
- Crop the source to the exact UI or evidence region. Do not show a whole
  desktop at postage-stamp size.
- Keep captions clear of the speaker's eyes, mouth, active hands, and the proof
  region.

## TAKEOVER

- Use full-screen for legibility-critical real proof, a before/after reveal, or
  a meaningful multi-state animation.
- Return to the speaker when the visual has completed its teaching job.
- Recompose editable `16:9` Remotion or Manim sources for `1080x1920`; do not
  letterbox the landscape master.
- Keep evidence labels and source context readable.

## QUIET

- Preserve uninterrupted A-roll for credibility, humor, a personal boundary,
  or the final reframe.
- Do not add motion merely to avoid silence.

## Default sequence

Use `FACE -> SPLIT -> TAKEOVER or proof emphasis -> FACE/QUIET` when the content
supports all four steps. Shorter reels may use only two modes. Change modes on
semantic beats, not on a fixed timer.

Keep essential information away from platform action rails and bottom caption
areas. Preview with the actual target-platform UI before export.
