# Resume Template Families

Choose the least decorative layout that makes the candidate's strongest
evidence easy to scan. All default families use one column, conventional
headings, selectable text, and a predictable reading order.

| Family | Best fit | Typical priority | Visual treatment |
|---|---|---|---|
| ATS Classic | General applications, conservative employers, mixed roles | Experience, skills, education, projects | Neutral type, black or restrained gray, compact rules |
| Technical Accent | Software, data, ML engineering, technical product | Skills, experience, technical projects, education | One restrained accent color, selective bold metrics and technologies |
| Research & Publications | Bioinformatics, computational biology, research, scientific software | Education, research experience, methods/skills, projects, selected outputs | Academic hierarchy, restrained accent, space for methods and publications |

## Selection Rules

- Use `ATS Classic` when the target is unclear or a portal's parsing behavior is
  unknown.
- Use `Technical Accent` when technical delivery, systems, and measurable
  engineering outcomes are the main screening signal.
- Use `Research & Publications` when scientific methods, datasets,
  reproducibility, publications, or biological interpretation are central.
- Keep contact information as text, not icons.
- Use color only as an accent; the document must remain understandable in
  grayscale.
- Avoid two-column layouts and sidebars by default. Use them only when the user
  explicitly prioritizes visual presentation over maximum ATS robustness.
- Change section order to match the target, but do not disguise missing
  evidence with layout.
