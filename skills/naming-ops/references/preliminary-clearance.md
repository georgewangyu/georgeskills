# Preliminary Clearance

Use this file when the task moves from ideation into screening.

## Official Sources

- USPTO trademark search landing page: `https://www.uspto.gov/trademarks/search`
- USPTO comprehensive clearance guidance: `https://www.uspto.gov/trademarks/search/comprehensive-clearance-search-similar-trademarks`
- USPTO strong trademarks guidance: `https://www.uspto.gov/trademarks/basics/strong-trademarks`
- ICANN lookup: `https://lookup.icann.org/en`

## Practical Interpretation

- Stronger names are usually arbitrary, suggestive, or coined. Descriptive and generic names are weaker and often harder to protect.
- A federal trademark screen is necessary but not sufficient. Similar marks, adjacent categories, state registrations, and live unregistered use can still create problems.
- Business entity availability is not the same as trademark availability.
- Domain availability is also not enough. A registered mark can still create risk even if a domain can be purchased.

## Minimum First-Pass Screen

1. Search the exact candidate in the USPTO system.
2. Search close variants:
   - merged and split forms
   - singular and plural
   - vowel swaps
   - common misspellings
   - dropped vowels or doubled letters
3. Search the open web for live use:
   - `"name" software`
   - `"name" app`
   - `"name" saas`
   - `"name" company`
   - `"name" brand`
4. Check state-level exposure where relevant:
   - secretary of state entity search
   - state trademark databases if the state exposes one
5. Check domain posture:
   - exact `.com` if that matters
   - realistic alternates such as `.io`, `.app`, `.co`
   - awkward fallback prefixes like `get`, `use`, `try` only if the brand is strong enough to justify them

## Risk Flags

Escalate or discard when:
- a similar mark exists in a closely related software or services class
- the candidate is descriptive of the product itself
- a well-funded company already uses the name in a nearby category
- the exact domain is parked by an obvious brand holder or active competitor
- the name has multiple plausible spellings or pronunciations

## Response Pattern

When reporting results, use labels such as:
- `low preliminary risk`
- `needs counsel review`
- `discard due to collision risk`

Avoid definitive legal claims.
